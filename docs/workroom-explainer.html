1. Synchronous SQLite Execution

Using better-sqlite3 eliminates async connection pooling lag. Database operations run in sub-millisecond synchronous transactions inside the Express worker process with Write-Ahead Logging (WAL).

2. Single Source of Truth

All views read from useWorkroomStore.ts. A status change in Kanban, a drag on Canvas, or an edit in List view triggers an optimistic update and syncs with backend without view drift.

3. Strict Zero-Slop Architecture

Every file strictly obeys the < 300 lines limit. Components are broken down into granular submodules like CanvasEpicFrame, CanvasDependencyEdges, and TaskAssigneeDropdown.

SECTION 03

Multi-View Synchronization Matrix

How the 4 native views interpret and display the exact same SQLite state with zero synchronization delay.

1. Linear-Style List View

Engineered for high-density keyboard workflows. Each row is fixed at 36px (h-9) with hairline borders, status icons, assignee avatars, and priority dots.

  • Collapsible Epic Sections: Groups tasks by Epic with progress bar.
  • Independent Tasks Group: Gracefully groups tasks with epic_id = null.
  • Inline Quick Add: + Thêm việc triggers keyboard-first creation.

2. Dual-Mode Kanban View

Fluid native HTML5 drag-and-drop between columns (todo → in_progress → review → done).

  • Flat Columns Mode: Classic 4-column overview of the entire sprint.
  • Epic Swimlanes Mode: Divides the board into horizontal lanes per Epic, plus a dedicated lane for independent tasks.
  • Live Lock Indicator: Shows subtle amber lock if prerequisites are incomplete.

3. FigJam 2D Spatial Canvas

Freeform visual ideation surface with infinite panning, wheel zoom, and absolute world coordinate tracking.

  • Magnetic Epic Frames: Dragging an Epic moves all internal tasks via (dx, dy) delta propagation.
  • Auto-Parenting on Drop: Dropping a task into an Epic sets epic_id automatically.
  • Interactive SVG Arrows: Real-time Cubic Bezier routing with midpoint deletion tags.

4. Shared Document Hub & @Mentions

A centralized team knowledge base modeled after Microsoft Teams Class Share and Notion Wiki docs.

  • Tri-Type Documents: Markdown manuals, external web links, and pinned quick notes.
  • Interactive @Mention Chip: Clicking @[Title](doc:ID) in any view slides open the doc viewer.
  • Inline Categorization: Filter by Architecture, Guidelines, Product, or General.

1. Task Center & Bounding Box Hit-Test

Calculated in canvasGeometry.ts. A task belongs to an Epic if its center point lies within the Epic's boundary box:

P_center = (task.canvasX + 120, task.canvasY + 50) isInside = ( P_center.x >= epic.canvasX && P_center.x <= epic.canvasX + epic.canvasWidth && P_center.y >= epic.canvasY && P_center.y <= epic.canvasY + epic.canvasHeight );

2. Cubic Bezier Curve Formula

Connects the source right port to the target left port with curvature proportional to distance:

curvature = Math.max(Math.abs(x2 - x1) * 0.5, 45); P0 = (x1, y1); P1 = (x1 + curvature, y1); P3 = (x2, y2); P2 = (x2 - curvature, y2); Path = `M ${P0.x} ${P0.y} C ${P1.x} ${P1.y}, ${P2.x} ${P2.y}, ${P3.x} ${P3.y}`; Midpoint(t=0.5) = 0.125*P0 + 0.375*P1 + 0.375*P2 + 0.125*P3;
SECTION 05

High-Craft Anti-Slop UI/UX System

Direct comparison showing how Mini Workroom eliminated generic AI template anti-patterns in favor of Notion/Linear/FigJam elegance.

Generic AI Slop Anti-Patterns (Banned)
  • Emoji text soup: Cluttering titles with 🔒, 📎, ☑, ⚠.
  • Pill-in-box nesting: Wrapping every subtask count in heavy borders and gray pills.
  • Dark-mode slate slop: Blinding neon emerald or glowing purple gradients on dark slate.
  • Persistent port distraction: Cluttering canvas cards with permanent + connection buttons.
  • Repetitive Epic badges: Repeating the epic badge inside cards already positioned inside an Epic container.
High-Craft Linear / FigJam Implementation
  • Lucide micro-icons: Standardized w-3.5 h-3.5 with refined strokeWidth={1.75}.
  • Flat inline typography: Metadata presented cleanly without box outlines.
  • Refined light palette: Pure white #FFFFFF cards against warm #F8F9FA dot matrix surface.
  • Hover-only ports: Connection anchors remain hidden (opacity-0) until user hovers over card.
  • FigJam floating headers: Clean badge anchored at -top-7 left-0 with 4% background tint.
